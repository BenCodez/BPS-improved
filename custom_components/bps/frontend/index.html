Phone receiver height survey (optional)

Use one common floor/property level for receiver and tracker heights. Enter the known phone height above that level, capture a reference, then visit each receiver within 15 minutes. Recapture the reference for a later visit.

Prefer your own Companion App pressure sensor when available; select it explicitly. Browser altitude requires location permission and finite vertical accuracy. If neither is usable, set mount height manually in Receiver properties.

Keep the phone still for 30–45 seconds per capture. Pressure spread measures precision, not proven absolute accuracy; weather and ventilation can shift it. GPS vertical uncertainty over 2 m is blocked. Confirmed heights are staged until Save Floor Plan; survey details stay in private storage and full diagnostic downloads.

Outdoor tracking: trees, buildings, fences & dog groups

Optional. Changes are persisted with Save Floor Plan. Environment shapes change measurement trust, not distance.

Long-range mode is beside Start tracking and saves immediately. Compare actual-location marks with it off and on; missing Bermuda quality data uses normal tracking.

Reduce trust in paths through mapped obstructions. Start with Standard. Higher settings also account for tree depth and can move estimates away from the real position; compare known-position snapshots before keeping a change.

Estimated uncertainty is a heuristic radius, not a guaranteed confidence interval. Grey dotted circles mark stale fixes.

Receiver Calibration

                    ❓
                        Compares the distances receivers measure between each other (each probe advertises an iBeacon) with their placed positions, and fits a per-receiver distance correction. Select the floor first, then sample while the house is quiet.
                    
                

                

                    
                    ❓
                        Samples in the background and checks every 15 minutes. Requires fresh, stable observations from at least four connected receivers, validates on a separate sampling period, and limits accepted changes to 10%. Keeps current corrections when evidence is weak. Survives Home Assistant restarts.

The test checks each beacon and location, comparing raw tracking with recorded versus proposed corrections; it does not apply them. Auto calibration still applies corrections automatically.
